## Hosting and maintenance

Static HTML and CSS; no build, JavaScript, external fonts, analytics or website cookies.

GitHub Pages: deploy from `main`, folder `/ (root)`. The `.nojekyll` file enables direct static hosting. Keep both languages synchronized when updating the text, and update the policy date when its substance changes.

- `index.html`: support, contact and FAQs
- `privacy.html`: privacy policy for the app and website
- `styles.css`: shared responsive layout

The privacy policy describes the current app behavior. Recheck it whenever data processing, service providers, purchases, storage or deletion behavior changes.
